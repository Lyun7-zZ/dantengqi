# 文档说明

`docs/` 下文件较多，这里说明哪个是当前版本、哪些只是历史存档。

## 当前版本

| 文件 | 说明 |
|---|---|
| `蛋疼棋_规则说明书_v1.2.docx` | **规则唯一事实来源**。棋盘、行动、平局判定、计时、悔棋都以它为准。改规则必须先改这份并升版本。 |

## 规划与数据

| 文件 | 状态 | 说明 |
|---|---|---|
| `蛋疼棋_需求总表_v1.1.docx` | 规划版 | 一、二期需求合并表。联机、存档、认输等是在此表之后实现的，**不代表当前进度**。当前进度以仓库 README 为准。 |
| `蛋疼棋_平衡测试报告_v1.0.docx` | 历史数据 | 基于 500 局自对弈测得先手胜率 48.7%、平局率 23.2%。规则与参数（228 墙位、容差 1）未变，结论仍成立；AI 强度已提升，绝对数值会有变化。 |

## 历史存档

`archive/` 里是规则说明书与需求总表的早期版本（v0.1 / v0.2 / v1.0 / v1.1 / v1.2），
仅供追溯决策过程，**不要作为实现依据**。

## 原始素材

`素材/` 是项目最开始的输入：

- `蛋疼棋游戏玩法.pdf`：最初的纸质规则；
- `蛋疼棋游戏功能需求（1期/2期）.docx`：甲方需求原文；
- `game.html`：2022 年的网页原型，仅作交互参考。
