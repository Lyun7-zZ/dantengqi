# G-test 预注册：G7+ vs G9+

## 目的

在固定宗师结构上，仅提高常规深度上限（7→9），检验额外计算能否改善对固定 3 秒宗师的实战棋力。

## 配置

| 项 | G7+ | G9+ |
|---|---|---|
| 结构 | 固定宗师 | 固定宗师 |
| maxDepth | 7 | 9 |
| endgameDepth | 9 | 9 |
| 预算 | 3,000ms + 100ms 缓冲 | 同 |
| 缓存 | 关闭 | 关闭 |
| evalRaceMode | legacy | legacy |
| 对手 | 固定宗师 3s，原配置 | 同 |

## 样本

- 开局：115–134，20 个全新开局（0–114 已用于历史实验）；
- 每臂 20 × 双座位 = 40 局，共 80 局；
- 种子：`101000 + openingId*2 + seat`；
- 8 shard，双臂交错，独立进程；
- 外层单调计时覆盖完整 AI 调用；记录动作、终局、来源、残局标志、深度、节点、耗时。

## 门槛（运行前冻结）

相对通过（全部满足）：

- G9+ 胜局 ≥ G7+；
- G9+ 负局 ≤ G7+ − 2；
- G9+ 的 L+U ≤ G7+；
- G9+ 积分 ≥ G7+；
- 非法 / 外部超时 = 0。

绝对参考：G9+ ≥28 胜、≤4 负、U=0。

方向性结果，不称统计显著；区间跨零时只作描述。
