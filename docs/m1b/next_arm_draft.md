# B2 对局快筛草案（未授权）

## 唯一变量

H1+C（`routeWalls=6` + 精确路径缓存）对 **H1+（同配置、缓存关闭）**，或对固定宗师 3s。
缓存是唯一差异；不改评估、计划、候选宽度、排序与限时。

## 规模

- 20 个全新开局（未用于 M0/M1 调参），双座位 = 40 局/臂；
- 固定宗师 3s，同硬件、同开局/种子，软截止 2,900ms；
- 轻量日志记录动作序列、末局面、终止理由，用于 U 分类。

## 判据

- 0 非法动作、0 超时；
- 配对积分与胜率不降，L+U 不升；
- 至少一项主目标改善；
- 不以 40 局声称达到 70%/10%，不追加样本至过线。

## 不做

- 不加增量更新、合法性短路、状态复制；
- 不启动 M3/M4，不新增 UI，不合并 main。
