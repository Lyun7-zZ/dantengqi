# M1b 资格预注册与结果

## 目标

验证「精确路径缓存」是否有资格进入对局快筛，不直接证明棋力提升。

## 冻结项

- 分支：`grandmaster-plus`；缓存默认关闭，仅实验配置启用
- 限时：3,000ms 硬预算，100ms 返回缓冲；软截止 2,900ms
- 缓存：决策内有界，键 = 52 位墙哈希 + 起点 + 查询类型；上限 200k，超限清空
- 状态集：23 个冻结状态（开局/中局/残局/合成）
- 固定工作量：深度 6，轮次 3 次，cache off/on 交错

## 门槛（预注册）

| 项 | 门槛 | 结果 |
|---|---|---|
| 语义一致 | 动作、节点数、评分无差异 | 通过（动作/节点全一致） |
| 固定工作量加速 | 中位 ≥15% | 通过（37.1%） |
| 限时压力 | ≥300 次，0 非法、0 超时 | 通过（300 次，最大 2,870ms） |
| 内存 | 有界，记录峰值/清空 | 通过（上限 200k，18 次决策清空 81 次） |

## 未覆盖

- 未按合法性/估值/候选场景拆分命中率；
- 未验证增量更新、合法性短路、状态复制等第二变量；
- 未做 40 局对局快筛；
- 300 次压力不能保证未来绝不越界。

## 结论

B1 通过资格，建议进入 B2 快筛（H1+C vs 固定宗师，20 新开局 × 双座位 = 40 局）；
不自动启动，需另行授权。
