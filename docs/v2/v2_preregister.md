# V2 预注册草案（E / C / F）

本轮只出草案，不实施。优先级：E（候选质量）> C（风险标签）> F（残局，F0 已否决）。

## E：候选质量与统一裁决原型

**问题**：现有选择性候选是否漏掉了更优动作？漏在生成、入搜还是排序？

**设计**：
- 对照组：H1+C 实际候选与动作；
- 实验组：同状态用更宽合法集合 + 多预算参考搜索生成候选质量标签；
- 固定资源，记录 generated/legal/entered/completed/selected；
- 按 openingId 隔离训练/验证，不把参考搜索当真值。

**资格门槛**：
- 至少 2 个独立开局出现重复的候选遗漏或排序反转；
- 保护局不得退化；
- 固定工作量耗时增幅 ≤10%；
- 300 次外部 3s 压力 0 非法/0 超时。

**MVP**：离线 top-k 命中率 + 固定状态动作一致性；不直接上线。

## C：风险标签与根节点裁决（条件式）

**问题**：能否用固定宗师条件下的 W/D/L 估计，降低负率而不牺牲胜率？

**设计**：
- 固定宗师 + 多种子续局，得到每个代表状态的 W/D/L/U 分布；
- 按 openingId 分组训练/校准/测试；
- 只在未证状态使用风险估计，已证胜/平优先；
- 参数在开发集冻结。

**资格门槛**：
- 标签稳定性与校准误差可接受；
- 保护集（已证胜/平）无退化；
- 40 局负率至少降 2 局、胜率不降、L+U 不升、积分不降；
- 0 非法/超时。

**风险**：单一最坏情况不是 CVaR；没有结果分布就不能称风险价值。

## F：定向残局求解（本轮否决）

F0 审计：默认 `wallLimit=Infinity`，B2b H1C 2,891 个候选决策中：
- 无合法墙状态：**0**；
- 最少合法墙：风险局 103、对照 71；
- 小状态（出口 ≤4 且双方距离 ≤5）：风险 3、对照 39。

结论：不存在「墙耗尽」子空间，F1 墙耗尽求解器不立项。若未来改用有限墙规则，需重新做 F0。

## 通用边界

- 不改固定宗师/地狱，不新增 UI，不合并 main；
- 一次只做一个变量；
- 40 局只做方向筛选，不称达标；
- 失败也归档，不选择性重跑。
