# E1 竞速评分预注册草案（未授权）

## 唯一变量

在 H1+C 上，仅替换 `evalAI` 中的竞速基值逻辑：

- 当前：`winning / drawish / behind` 三档固定基值 +6000 / −60 / −5400；
- 草案：在「无未来封墙」假设下，模拟双方按最短到达轮次的越线序列，按规则 1.3 判定 W/D/L，并把结果转成连续竞速分；
- 结构项 `ways / near / doorstep / openPenalty` 保留，不新增同类权重复。

## 资格验证

| 项 | 要求 |
|---|---|
| 规则边界 | 等距、领先 1 步、领先 2 步、先手/后手、单出口；W/D/L 与规则引擎一致 |
| 奇偶稳定 | 固定深度 5/6/7，分数符号与最优动作一致或差异可解释 |
| 保护局 | 已证胜局不被降级为平/负 |
| 独立证据 | 至少 2 个独立开局支持同一机制 |
| 成本 | 固定工作量中位耗时增幅 ≤10% |
| 压力 | 300 次 3s：0 非法、0 超时 |

## 若资格通过

- 不达标则停止，不逐局调参。
