# M0 后续单变量实验草案（未授权）

## 先修工程问题

M0 的 H0 出现 1 次单步 3,013ms（opening 69 / 后手），超过 3,000ms 硬边界 13ms；H1 无超时。
在进入棋力优化前，M1 的第一项应是**入口到返回的 deadline 审计**：

- 记录 plan / 候选 / 排序 / 搜索 / 返回各段耗时；
- 确认计划阶段是否在 globalDeadline 检查之前完成；
- 预留返回缓冲，保证 tTotal ≤ 3,000ms；
- 只改计时与安全回退，不改搜索策略。

## 基线

M0 建议基线：H1（A1，routeWalls=6），理由见 `M0基线报告_2026-11-25.docx`。
H0 的积分略高（+0.013），但在越界修复后可重新评估。
