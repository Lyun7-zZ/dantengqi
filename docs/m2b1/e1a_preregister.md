# E1a 实施与 M2c 预注册草案

## E1a 实现

- 配置项 `evalRaceMode`：`legacy`（默认）/ `race`；
- 仅宗师+ 实验配置可启用，固定宗师与 28 秒地狱保持 legacy；
- `race` 只替换非终局三档基值为静态竞速 W/D/L：
  - W → +6000
  - D → −60
  - L → −5400
- 结构项仍按旧分档选择；候选、排序、计划、缓存、限时、深度全部冻结。

## 静态竞速

`T_M = 2dM − 1`，`T_O = 2dO`，`m = dO − dM`：

- `m ≥ 0`：M 先越线，O 剩余 `m+1`；
- `m < 0`：O 先越线，M 剩余 `−m`；
- 按 `firstOnly` + `tolerance` 判 W/D/L。

## 资格结果

| 项 | 结果 |

## M2c 预注册（未授权）

- 对照：H1+C（legacy）；
- 实验：H1+C + E1a（race）；
- 20 个全新开局 × 双座位 = 40 局/臂，共 80 局；
- 固定宗师 3s、同种子/硬件/缓存/限时；
- 判据：0 非法/超时；胜局不减、败局至少减 2、L+U 不升、积分不降；
- 不达标不重跑，不自动进 M3。

## 禁止

- 同时改结构项、候选宽度、排序、计划、搜索预算；
- 修改固定宗师或地狱；新增 UI；合并 main；
- 用 E1a 资格结果宣称棋力提升。
