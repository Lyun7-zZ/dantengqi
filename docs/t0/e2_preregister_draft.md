# E2 路径脆弱性预注册草案（未授权）

## 问题

是否存在「一墙造成大幅绕路 / 关键通路冗余被评估忽略」的失败机制。

## 方法（仅离线，不改算法）

1. 固定状态集：B2b 失败局关键节点 + 胜局对照 + 规则边界；
2. 对每个状态逐墙计算：
   - 对手最短路增量；
   - 己方自损；
   - 对手路径条数（cap=24）及饱和率；
   - 是否共享瓶颈边；
3. 比较失败局与胜局对照的分布，报告相关性，不直接加权重。

## 资格门槛（建议）

- 至少 2 个独立开局支持同一类路径脆弱性；
- 保护局无已证胜→平/负退化；
- 规则测试全通过；
- 若做在线实验，固定工作量耗时增幅 ≤10%，300 次 3s 压力 0 非法/0 超时。

## 边界

- 不实现 T1/T2；
- 不改评估权重、候选、排序、计划；
- 不改固定宗师/地狱，不新增 UI，不合并 main；
- 不达标则停止，不逐局调参。
