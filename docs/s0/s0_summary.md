# S0 多策略对抗原型结果

## 实现

- 独立模块 `src/s0-planner.js`，默认不接入生产；
- ACS 度量：`M = D_O − D_M`，对手应手取最坏；
- 提议器：advance、attack、protect（不强制）；
- 对手应手：走子 + 攻击墙 + 保护墙；
- 3 秒整次预算，100ms 缓冲；无坐标特例。

## 24 状态

- 16 个 B2b H1C 历史状态（8 风险 + 8 胜局）；
- 8 个构造状态：SBP 口袋、D12/H11 复杂局面、开放竞速、近端攻击、双方保护、多步。

## 结果

| 指标 | 结果 |
|---|---|
| 非法 | 0 |
| S0 最大耗时 | 184ms |
| H1+C 最大耗时 | 2,859ms |
| S0 策略 | advance 16、attack 8、protect 0 |
| 反制后 M 差 | 7 局 +1、1 局 +2、16 局持平 |

关键案例：

- SBP 口袋：H1+C 选 h(1,10)，M 后 1；S0 选 up，M 后 2；
- D12/H11：双方都选 up，M 后 0；
- 双方保护/多步：双方都选推进，M 后 1。

## 判定

- 规则、合法性、限时通过；
- 策略切换只覆盖 advance/attack，protect 从未被选中；
- 原型优化的是即时最坏 M，没有为多回合牵制定价；
- 不能称为已实现多策略 ACS；
- 保留默认关闭原型，不进入实战。

## 压力

300 次：0 非法、0 超时，最大 169ms，p99 164ms。
