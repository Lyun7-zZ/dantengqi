# S1 多步抗牵制原型结果

## 实现

- `src/s1-planner.js`，默认关闭；
- 统一根方视角 `M = D_O − D_M`；
- 有限时域 V_h：h=1/3/5/7，对手 min、己方 max，终局优先；
- 三臂：s0（原候选+浅层）、deep（同候选加深）、s1（分级候选+加深+牵制反制墙）；
- 候选：全部走子 + 攻击墙 + 局部的 protect 墙 + 己方路径上的牵制反制墙；
- 3,000ms 硬上限、100ms 缓冲。

## 修复

- D12/H11 fixture 原缺 `h(3,10)`、`h(7,9)` 两道横墙，导致 up 非法却返回 up；
- 补墙后 up 被规则拒绝，距离 13:12；
- 修复 protect 标签：只保留己方路径附近、零距离损失的墙，避免零收益墙挤占候选。
